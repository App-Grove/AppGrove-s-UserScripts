# UserScriptヘッダーの`@`ディレクティブ一覧

ヘッダーは `// ==UserScript==` と `// ==/UserScript==` の間に記述します。以下は主にTampermonkey/Violentmonkeyで共通のものです。

## 1. 識別・メタ情報

| ディレクティブ | 内容 |
|---|---|
| `@name` | スクリプト名。**必須**。`@name:ja` のようにロケール別指定が可能 |
| `@namespace` | 名前の衝突を避ける識別子。`@name` との組で一意になる。URLや自分のドメインを使うのが慣例 |
| `@version` | バージョン。自動更新時の新旧比較に使われる(`1.0.1` > `1.0.0`) |
| `@description` | 説明文。`@description:ja` も可 |
| `@author` | 作者名 |
| `@license` / `@copyright` | ライセンス表記(例: `MIT`) |
| `@icon` / `@icon64` | 管理画面に表示するアイコンのURL |
| `@homepageURL` / `@supportURL` | 配布ページ/サポート先(Issueページ等) |
| `@tag` | 分類用タグ |
| `@antifeature` | 広告・追跡など、利用者に不利な機能の申告(Greasy Fork等で使用) |

## 2. 実行対象URLの制御

| ディレクティブ | 内容 |
|---|---|
| `@match` | 実行対象URLパターン。厳格な形式 `<scheme>://<host>/<path>`。`*` はワイルドカード、`<all_urls>` で全URL。**推奨** |
| `@include` | グロブ(`*`)または正規表現(`/.../`)で指定。`@match` より緩く、柔軟 |
| `@exclude` | 除外パターン(`@include` と同形式) |
| `@exclude-match` | `@match` 形式の除外パターン |
| `@noframes` | iframe内では実行しない(トップフレームのみ) |

```
// @match https://*.example.com/path/*
// @exclude-match https://www.example.com/path/admin/*
```

## 3. 実行タイミング・環境

| ディレクティブ | 内容 |
|---|---|
| `@run-at` | 実行タイミング。下記参照 |
| `@sandbox` | (Tampermonkey)`raw` / `JavaScript` / `DOM`。ページのJSとの隔離レベル |
| `@inject-into` | (Violentmonkey)`page` / `content` / `auto`。注入先コンテキスト |
| `@unwrap` | (Tampermonkey)スクリプトを関数で包まず直接注入 |
| `@top-level-await` | (Tampermonkey)トップレベルawaitを有効化 |

`@run-at` の値:
- `document-start`: DOM構築前。最速
- `document-body`: `<body>` が存在した時点
- `document-end`: DOMContentLoaded 付近(**既定値**)
- `document-idle`: DOMContentLoaded 後
- `context-menu`: 右クリックメニューから手動実行

## 4. 権限・外部リソース

| ディレクティブ | 内容 |
|---|---|
| `@grant` | 使用するGM APIを宣言。`GM_setValue`、`GM_xmlhttpRequest`、`GM.getValue`(Promise版)、`unsafeWindow` など。`none` 指定でサンドボックスなし(ページコンテキストで実行)。**宣言していないAPIは使えない** |
| `@connect` | `GM_xmlhttpRequest` の通信先ドメインを許可。`*`、`localhost`、`self` も指定可 |
| `@require` | 実行前に読み込む外部JS。`#sha256=...` でSRI検証が可能 |
| `@resource` | `名前 URL` 形式で外部リソース登録。`GM_getResourceText` / `GM_getResourceURL` で取得 |

```
// @grant GM_setValue
// @grant GM_getValue
// @connect api.example.com
// @require https://cdn.jsdelivr.net/npm/dayjs@1.11.10/dayjs.min.js
// @resource css https://example.com/style.css
```

## 5. 自動更新

| ディレクティブ | 内容 |
|---|---|
| `@updateURL` | 更新確認用URL(ヘッダーのみの `.meta.js` でも可) |
| `@downloadURL` | 更新時にダウンロードするスクリプト本体のURL |

`@version` が上がった場合のみ更新されます。

## 実用的なヘッダー例

```js
// ==UserScript==
// @name         Example Script
// @name:ja      サンプルスクリプト
// @namespace    https://example.com/
// @version      1.0.0
// @description  Example description
// @author       yourname
// @match        https://example.com/*
// @run-at       document-end
// @grant        GM_setValue
// @grant        GM_getValue
// @noframes
// @license      MIT
// ==/UserScript==
```

## 注意点

- `@grant` を1つでも指定するとサンドボックス内で動作し、ページ側の変数には `unsafeWindow` 経由でアクセスする必要があります。
- `@include` と `@match` の併用は可能ですが、特別な理由がなければ `@match` に統一してください。
- 拡張機能(Tampermonkey/Violentmonkey/Greasemonkey)ごとに対応ディレクティブが異なります。使用する環境の公式ドキュメントで確認してください。

特定のディレクティブ(`@grant` のAPI一覧など)をさらに掘り下げることもできます。

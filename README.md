# AppGrove's UserScripts
AppGroveが管理するUserScriptリストです。ViolentMonskeyでの使用を想定しています。  
  
## 使い方
Violentmonkey(もしくは他のUserScriptマネージャー)をインストールしたブラウザでインストールしたいユーザースクリプトの「インストール」リンクをクリックしてください。  
  
### ViolentMonkeyインストール
Chrome系ブラウザ: [Violentmonkey - Chrome ウェブストア](https://chromewebstore.google.com/detail/violentmonkey/jinjaccalgkegednnccohejagnlnfdag)  
FireFox系ブラウザ: [Violentmonkey - Add-ons for Firefox](https://addons.mozilla.org/ja/firefox/addon/violentmonkey/)  
Edge: [Violentmonkey - Microsoft Edge Addons](https://microsoftedge.microsoft.com/addons/detail/violentmonkey/eeagobfjdenkkddmbclomhiblgggliao)  
手動インストール: [Violentmonkey - GitHub](https://github.com/violentmonkey/violentmonkey)  
  
## UserScript一覧
### Twitter
#### Show All Posts on Twitter/X Profiles
Twitterのプロフィールページで、デフォルトで「ポスト」ではなく「すべて」を表示するようにします。

[インストール](https://github.com/App-Grove/AppGrove-s-UserScripts/raw/refs/heads/main/scripts/x-show-all-posts-on-profiles.user.js)
```
https://github.com/App-Grove/AppGrove-s-UserScripts/raw/refs/heads/main/scripts/x-show-all-posts-on-profiles.user.js
```

#### Open Twitter/X Media Tab to Photos by Default
Twitterのメディア欄を開いたとき、デフォルトでひらくものを動画から画像に変更します。

[インストール](https://github.com/App-Grove/AppGrove-s-UserScripts/raw/refs/heads/main/scripts/x-media-opens-on-photos.user.js)
```
https://github.com/App-Grove/AppGrove-s-UserScripts/raw/refs/heads/main/scripts/x-media-opens-on-photos.user.js
```
